## Paper format

Each catalog entry points to a standalone paper at `PAPER.md`. Evidence ledgers, source logs, and reproduction files live in its `supporting/` directory.

For future papers, use this minimal folder convention:

```text
papers/
  <area>/
    <paper-slug>/
      PAPER.md
      supporting/
```
