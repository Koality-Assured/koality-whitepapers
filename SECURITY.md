# Security Policy

## Supported Versions

Currently, the primary supported branch is `main`.

## Reporting a Vulnerability

We use GitHub Private Vulnerability Reporting for all security issues. Please do not report security vulnerabilities through public GitHub issues.

To report a security vulnerability, please go to the [Security tab](https://github.com/Koality-Assured/koality-whitepapers/security/advisories/new) of this repository and report it privately.
