| **S4** | [Anthropic Claude Code Subagent Architecture](https://code.claude.com/docs/en/sub-agents) | Product docs; accessed 2026-10-12 | Establishes that Claude Code subagents execute in isolated context windows with configurable tool sets and optional `isolation: worktree`. | Context window isolation prevents direct transcript bleeding, but initial task prompt sizing is caller-determined. |
| **S5** | [Lost in the Middle: How Language Models Use Long Contexts](https://arxiv.org/abs/2307.03172) | Liu et al., TACL 2024 / arXiv:2307.03172; accessed 2026-10-12 | Establishes "Lost in the Middle": LLM retrieval performance follows a U-shaped curve; information placed in the middle of long contexts degrades significantly. | Tested on question answering and key-value retrieval; does not measure multi-turn autonomous tool use directly. |
| **S6** | [Chroma Research: Context Rot Analysis](https://trychroma.com/research/context-rot) | Published July 2025; accessed 2026-10-12 | Establishes "Context Rot": as input context increases, models suffer attention dilution and semantic interference from distractor text, causing reasoning failures beyond simple lexical retrieval. | Evaluated across open-weights and proprietary models on synthetic needle tasks; specific degradation curves vary by model checkpoint. |
| **S7** | [OpenAI Responses API & Prompt Caching Guides](https://developers.openai.com/api/docs/guides/prompt-caching) | Living documentation; accessed 2026-10-12 | Establishes prefix matching rules, 1,024-token minimum caching threshold, and usage reporting (`cached_tokens`, `cache_write_tokens`). | Caching reduces per-token read price by 50% but does not eliminate latency or execution costs; cache eviction occurs after inactivity. |
| **S8** | [Anthropic Prompt Caching Specification](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) | Living documentation; accessed 2026-10-12 | Establishes explicit `cache_control` breakpoints (up to 4), 5-minute ephemeral TTL, and cache write / read accounting fields. | Breakpoint positioning requires strict prefix determinism; subagent invocations create cache writes if prefixes diverge. |
| **S9** | [Google Gemini Context Caching Architecture](https://ai.google.dev/gemini-api/docs/caching) | Living documentation; accessed 2026-10-12 | Establishes explicit context cache objects, minimum token counts (32,768 tokens for Gemini 1.5 Pro), and hourly storage billing. | Explicit caching requires pre-allocated resources; dynamic conversational turns cannot be cached without explicit allocation. |
| **S10** | [tiktoken 0.14.0 package page](https://pypi.org/project/tiktoken/0.14.0/) and [source repository](https://github.com/openai/tiktoken) | Version 0.14.0; accessed 2026-10-12 | Published package metadata, release artifacts, and explicit `get_encoding('o200k_base')` tokenizer mapping. | Local tokenizer mapping only; does not include proprietary provider message framing. |
| **S11** | [Python 3.13.16 Release](https://www.python.org/downloads/release/python-31316/) and [uv 0.12.23 Release](https://github.com/astral-sh/uv/releases/tag/0.12.23) | Pinned releases; accessed 2026-10-12 | Official runtime release identity and dependency management binaries used in the benchmark environment. | Runtime pinning guarantees local reproducibility; does not validate cross-OS portability. |
