# Primary-source access log and bibliography

All authoritative standards, technical papers, vendor specifications, and repository benchmarks cited in [PAPER.md](../PAPER.md) were accessed and verified on 2026-11-04.

| **S1** | Robertson & Zaragoza: *The Probabilistic Relevance Framework: BM25 and Beyond* | Foundations and Trends in Information Retrieval, Vol. 3, No. 4 (2009) | `https://doi.org/10.1561/1500000019` | Mathematical foundations of BM25 term weighting, document length normalization ($b$), and term frequency saturation ($k_1$). | Information retrieval theory; does not address LLM context economics or tool loop mechanics. |
| **S2** | Liu et al.: *Lost in the Middle: How Language Models Use Long Contexts* | Transactions of the Association for Computational Linguistics (TACL 2024) / arXiv:2307.03172 | `https://arxiv.org/abs/2307.03172` | Demonstrates significant degradation in retrieval accuracy when target information resides in the middle of long context sequences. | Evaluated primarily on synthetic key-value retrieval and single-turn QA. |

| **S4** | Herrington / ast-grep Specification | Living Standard (Release 0.45+) | `https://ast-grep.github.io/` | Syntax-aware code pattern matching and symbol outline extraction across Concrete Syntax Trees via Tree-sitter. | Syntactic tree parsing; cannot resolve dynamic cross-file type hierarchies or runtime reflections. |

| **S6** | Gemini API Context Caching | Current official documentation; accessed 2026-11-04 | `https://ai.google.dev/gemini-api/docs/caching` | Documents implicit caching, model-specific minimum input counts, stable-prefix guidance, and `usage.total_cached_tokens` telemetry. | Provider- and model-specific; pricing and cache behavior can vary by API and model. |
